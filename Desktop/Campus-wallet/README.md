# Campus Wallet - RU Stable

A smart campus wallet application for Rutgers University students.

## Features

- **Budgeting and Spending**: Track meal swipes, flex dollars, and regular income in one simple, real-time view
- **My Activity**: Unified timeline of events, check-ins, and campus activities
- **Rewards and Incentives**: Earn rewards for positive financial habits

## Getting Started

Simply open `index.html` in your web browser. No build process or dependencies required!

You can also use a local server:
```bash
# Using Python
python -m http.server 8000

# Using Node.js (if you have it installed)
npx http-server
```

Then open `http://localhost:8000` in your browser.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts (Zen Dots, Inter, Inria Sans)
