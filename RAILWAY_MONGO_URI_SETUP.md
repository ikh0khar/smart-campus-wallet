# Railway MongoDB URI Setup - Step by Step

## If You're Creating a NEW MongoDB Service in Railway

When Railway shows fields for `mongo_uri` and `choice`:

### Option 1: Let Railway Auto-Generate (Easiest)
- **Leave them empty** ✅
- Railway will automatically create a MongoDB instance
- Railway will auto-generate the connection string
- You'll find it in the MongoDB service's Variables tab as `MONGO_URL`

### Option 2: Use Custom URI
- Fill `mongo_uri` with your MongoDB connection string (only if you have one already)
- Otherwise, **leave it empty** ✅

## What to Do AFTER MongoDB Service is Created

1. **Go to your MongoDB service** (the one you just created)
2. **Click "Variables" tab**
3. **Look for `MONGO_URL`** - This is auto-generated by Railway
4. **Copy that entire value** (looks like: `mongodb://mongo.randomstring.up.railway.app:27017`)

## Then Set in Your Web Service

1. **Go to your Web Service** (Node.js app)
2. **Click "Variables" tab**
3. **Click "+ New Variable"**
4. **Name:** `MONGODB_URI` (exactly this name)
5. **Value:** Paste the `MONGO_URL` you copied from MongoDB service
6. **Click "Add"**

## Summary

- **When creating MongoDB service:** `mongo_uri` and `choice` can be **empty** ✅
- **After MongoDB is created:** Get `MONGO_URL` from MongoDB service Variables
- **In your Web Service:** Add new variable `MONGODB_URI` with the `MONGO_URL` value
- **Redeploy** your web service

## Common Confusion

- ❌ **Wrong:** Setting `MONGODB_URI` in the MongoDB service itself
- ✅ **Right:** MongoDB service has `MONGO_URL` → Copy to Web Service as `MONGODB_URI`

- ❌ **Wrong:** Trying to set `MONGODB_URI` when creating MongoDB service
- ✅ **Right:** Create MongoDB first, then copy its `MONGO_URL` to your Web Service

## Still Confused?

1. **Create MongoDB service** - Leave form fields empty, just click "Add"
2. **Wait for it to deploy** (30 seconds)
3. **Click on the MongoDB service** → "Variables" tab
4. **Copy `MONGO_URL`** value
5. **Go to Web Service** → "Variables" tab → Add `MONGODB_URI` = (paste value)
6. **Redeploy web service**

That's it! 🎉
