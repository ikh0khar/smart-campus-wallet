# Quick Start Guide

## ⚠️ Important: Always Run Commands from Project Directory

**You must be in the project directory to run npm commands!**

### Navigate to Project Directory First

```bash
cd /Users/veerpatel/Hackfest2025/smart-campus-wallet
```

Then run your npm commands.

## Common Commands

### Install Dependencies
```bash
cd /Users/veerpatel/Hackfest2025/smart-campus-wallet
npm install
```

### Start Server
```bash
cd /Users/veerpatel/Hackfest2025/smart-campus-wallet
npm run dev
```

### Test Connection
```bash
cd /Users/veerpatel/Hackfest2025/smart-campus-wallet
npm run test:connection
```

## How to Check You're in the Right Directory

```bash
# Check current directory
pwd

# Should show:
# /Users/veerpatel/Hackfest2025/smart-campus-wallet

# Verify package.json exists
ls package.json

# Should show:
# package.json
```

If you're not in the right directory, navigate there first:
```bash
cd /Users/veerpatel/Hackfest2025/smart-campus-wallet
```
